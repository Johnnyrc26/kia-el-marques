# Kia El Marqués - Políticas y Redirección Oficial

Proyecto web para **Kia El Marqués** (concesionario oficial autorizado de la red Kia en Venezuela).

## 📌 Comportamiento del Sitio
- **`index.html` (Raíz / `kiaelmarques.com`):** Redirecciona automáticamente al portal oficial nacional de Kia Venezuela ([kia.com.ve](https://kia.com.ve)) mediante meta refresh y JavaScript, con pantalla de contingencia accesible.
- **`politica-de-privacidad.html`:** Documento legal completo de tratamiento de datos personales, garantías y derechos de privacidad.
- **`terminos-y-condiciones.html`:** Términos de uso, alcance de cotizaciones, garantías y propiedad intelectual.

## 📁 Estructura del Proyecto

```text
kia-el-marques/
├── index.html                   # Redirección inmediata hacia https://kia.com.ve
├── politica-de-privacidad.html   # Interfaz de Política de Privacidad
├── terminos-y-condiciones.html  # Interfaz de Términos y Condiciones
├── css/
│   └── styles.css               # Estilos oficiales y responsivos
├── js/
│   └── main.js                  # Manejo accesible de menú y año dinámico
├── assets/
│   └── kia-logo.svg             # Logotipo oficial de Kia (SVG)
└── .gitignore
```
